# Fraud Shield Banking System 💳🔐

## 📌 Project Description
A secure banking fraud detection system designed to identify suspicious transactions and enhance user security.

## 🚀 Features
- User Authentication (Login/Register)
- Fraud Detection System
- Secure Transactions
- Backend API with Node.js
- Frontend Interface

## 🛠 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB

## 📂 Project Structure
- Fraud-Sheild-backend/
- Fraud-Sheild-frontend/
